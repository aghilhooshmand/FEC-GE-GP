# Supplementary material index

Every file in this folder is listed here once. The manuscript cites items only by their id
(for example "Table S2"). `python paper_tables.py` checks this index against the folder and the
manuscript, fills the size and committed columns, and writes `paper/tables/supplementary.tex`.

Ids follow MDPI: `Figure Sn` for figures, `Table Sn` for CSV/Excel tables, `File Sn` for PDFs and
other documents. Files over 5 MB are git-ignored and recreated from their source.
